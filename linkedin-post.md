I built an Access Review Automation Tracker to practice a common IT support and security operations workflow: validating whether users have the correct access.

The project compares current user permissions against an approved access list and flags potential issues that need review.

Technical details:
- Built with Python
- Reads current access and approved access from CSV files
- Detects unauthorized access
- Detects missing required access
- Flags inactive users who still have permissions
- Exports a simple review report for follow-up

Why this matters:
Access management is a key part of IT support. Even small mistakes can create security risk, audit issues, or user productivity problems. Automating basic checks helps teams find exceptions faster and maintain cleaner access records.

Result:
A practical CLI MVP that demonstrates access review logic, CSV automation, reporting, and security-focused thinking.

This can be extended into a web dashboard, approval workflow, email notification system, or integration with identity platforms.
