# Access Review Automation Tracker

A small CLI tool that compares user access records against an approved access list and flags mismatches. It helps simulate access review checks often used in IT support and security operations.

## What it does

Compares two CSV files, identifies unauthorized access, missing access, and inactive users with active permissions, then exports a review report.

## Install

```powershell
npm install
```

## Run

```powershell
npm run dev
```

## Test

```powershell
npm run lint
npm run typecheck
npm test
npm run build
```
